# Migration Tasks — CoolStore Java EE 7 → Quarkus 3.8.1 on OpenShift

> Generated by mig-plan (MigIQ Planner stage). Foundation: `mig-prompt-workspace/migration-prompt.md`.
> Knowledge graph: rgctl index (36,511 nodes / 127,928 edges; `.rgctl/migration_plan.json`).
> Task-group order follows the rgctl Java package migration order
> (`model` → `utils` → `weblogic.application` → `rest` → `service`) and the phased
> completion strategy from the migration prompt. Integration hooks
> (**Test Generation** / **Containerization** / **Deployment**) are executed by the
> dedicated MigIQ execute / containerize / deploy stages in fresh sessions.

**Current state (verified in code):** main source (26 classes) fully on `jakarta.*`
imports, Quarkus 3.8.1 pom, SmallRye Kafka messaging, Flyway + H2 dev/test config in
place. Remaining: 1 test file with `javax.jms` imports, no `@RolesAllowed`/`@PermitAll`
on endpoints, no `quarkus-smallrye-health`, legacy `web.xml`/`beans.xml`/WebLogic
shims/JSPs, frontend not served from `META-INF/resources`, no `%prod` PostgreSQL
datasource, no container image or OpenShift manifests.

## Dependency Order (execution gates)

```
TG1 (baseline) ──► TG2 (cleanup) ──► TG3 (frontend/health) ──► TG4 (security)
                                       │
                                       └──► TG5 (data/config) ──► TG6 (image) ──► TG7 (OpenShift) ──► TG8 (parity & sign-off)
```

- TG3 must precede TG6/TG7 (health endpoints + static assets change image content)
- TG4 and TG5 may proceed in parallel after TG3; both feed TG6's env contract
- TG6 must precede TG7; TG7 must precede TG8
- Rollback point exists at every task-group gate (git branch + prior phase's
  deployable remains the fallback until TG8.8)
