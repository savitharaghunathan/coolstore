# Migration Tasks — CoolStore Java EE 7 → Quarkus 3.8.1 on OpenShift

> Generated by MigIQ Planner (mig-plan). Foundation: `mig-prompt-workspace/migration-prompt.md`.
> Knowledge graph: `.rgctl/` (discover 2026-10-28). Package order from `migration_plan.json`:
> `com.redhat.coolstore.model` → `com.redhat.coolstore.utils` → `weblogic.application` (remove) → `com.redhat.coolstore.rest` → `com.redhat.coolstore.service`.
> Translation rules: cite `migration/RULEBOOK.md` — do not invent new patterns.

**Context**: The bulk javax→jakarta/Quarkus translation is already complete (0 `javax.*` imports in main sources; pom targets Quarkus BOM 3.8.1). Remaining work: remove Java EE remnants, close production configuration gaps (PostgreSQL, Keycloak, audit library), validate behavior parity, containerize, and deploy to OpenShift.

## Dependency Order (execution sequence)

```
TG1 (cleanup)  ─┬─→ TG2 (model/utils) ─┐
                └─→ TG5.1–5.2 (config) │
                                        ├─→ TG3 (services/messaging) ─→ TG4 (REST/front end) ─→ TG6 (parity/tests) ─→ TG7 (container) ─→ TG8 (OpenShift) ─→ TG9 (handoff)
```

Hard gates:
- TG3 cannot start before TG2 (services depend on models/transformers)
- TG6 cannot complete before TG5 (tests need prod-like profiles and OIDC)
- TG7 cannot start before TG6 green (never containerize unverified code)
- TG8 cannot start before TG7 image exists
- TG3.1 (transaction audit) is the highest runtime-risk item — do it first within TG3
